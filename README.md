# 🚧 Pothole Detection Using YOLO | Custom Object Detection Model in Google Colab

This repository contains the full implementation of a **Pothole Detection System** using **YOLO11**.  
The notebook covers everything from dataset downloading to training, testing, and visualizing object detection results.

---

## 🔥 Features
- ✔ Automatic dataset download using **gdown**  
- ✔ Organize files into the correct YOLO folder structure  
- ✔ Create `pothole.yaml` programmatically  
- ✔ Train YOLO11 with custom parameters  
- ✔ Use early stopping & best checkpoint saving  
- ✔ Visualize detections using custom bounding boxes  
- ✔ Display 16 random test results in a 4×4 grid
